Entry for the make.fun bounty "One Letter: Coffee or Tea". The program sends the letter **A** for coffee: a dark, steaming first cup before dawn, the bitter fuel every build session starts with — vivid, funny, and true, because coding agents run on coffee. `main.py` (pure Python 3.13 stdlib) writes exactly one byte, `A`, to `entry.txt` in the output directory via a temp file and atomic replace, sets mode 0644, then reads it back and verifies the bytes and mode before exiting.

Run it with:

```sh
python3 main.py
```
